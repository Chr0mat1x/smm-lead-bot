# SMM-бот: поиск клиентов без сайта

Телеграм-бот, который находит малые бизнесы без своего сайта (кафе, кофейни, бани,
салоны, автомойки, автосервисы) и готовит для каждого персональное сообщение с
предложением сделать сайт и автоматизацию.

## Что бот делает и чего не делает

Делает:
- ищет бизнесы **без сайта** по открытым данным OpenStreetMap;
- собирает контакты: телефон, Telegram, Instagram, VK, email — что есть в данных;
- считает приоритет (кого обходить первым), склеивает филиалы одной сети;
- генерирует персональное сообщение под тип бизнеса (кафе и баня продают по-разному);
- ведёт базу со статусами: новый / одобрен / отправлен / ответил / не писать;
- **общается с вами как ассистент**: вы пишете «это не тот контакт» — он убирает
  лид, берёт следующий или переписывает письмо;
- выгружает лиды в CSV.

**Не делает: не рассылает спам автоматически.** И это осознанное решение, а не
недоделка — см. следующий раздел.

## Разговор с ассистентом

Бот понимает обычный текст, не только команды. Достаточно написать ему:

- «найди клиентов в Екатеринбурге» — запустит поиск;
- «покажи следующие» — выдаст ещё лиды;
- «статистика» — покажет базу;
- ответьте (reply) на карточку лида и напишите «это не тот контакт» — бот
  пометит его неподходящим и предложит следующего;
- «перепиши письмо короче» в ответ на карточку — обновит текст;
- «у него телефон в другом районе» — поправит контакт.

Команды: `/ask вопрос`, `/reset` (забыть историю), `/find Город`.

Чтобы это работало как настоящий диалог, нужен ключ LLM — см. «Нейросеть» ниже.
Без ключа бот не ломается: он понимает простые команды из списка выше, но
свободно поговорить не сможет и честно об этом скажет.

### Бесплатно, без регистрации и ключей

Самый простой путь — бесплатный публичный API Pollinations (модель GPT-OSS 20B).
Он умеет вызывать функции, поэтому ассистент полноценно правит лиды:

```bash
LLM_PROVIDER=pollinations
```

Больше ничего вписывать не нужно. Этот режим уже включён в проекте по умолчанию,
и он проверен вживую: бот получает «это не тот контакт» и реально отклоняет лид.

Учтите про бесплатные тарифы:
- это публичный сервис, у него есть лимиты и бывают задержки;
- не отправляйте туда персональные данные клиентов (в запрос уходит история диалога);
- сервис может быть недоступен в конкретный момент — тогда бот переключается
  на запасной режим и честно об этом сообщает.

Если нужна стабильность, возьмите бесплатный ключ у провайдера с щедрым лимитом
(Google AI Studio / Groq) — см. таблицу ниже. Настройка одна и та же.

### Какой вариант LLM выбрать

| Вариант | Что вписать в `.env` | Комментарий |
|---|---|---|
| **Pollinations** | `LLM_PROVIDER=pollinations` | **бесплатно и без ключа, уже включено** |
| OpenAI | `LLM_PROVIDER=openai`, `LLM_MODEL=gpt-4o-mini` | нужен `LLM_API_KEY` |
| OpenRouter | `LLM_PROVIDER=openai`, `LLM_BASE_URL=https://openrouter.ai/api/v1` | доступ к Claude и другим моделям |
| Groq | `LLM_PROVIDER=openai`, `LLM_BASE_URL=https://api.groq.com/openai/v1`, `LLM_MODEL=llama-3.3-70b-versatile` | быстро, есть бесплатный лимит |
| Claude | `LLM_PROVIDER=anthropic`, `LLM_MODEL=claude-3-5-sonnet-latest` | `LLM_API_KEY=sk-ant-...` |
| Ollama | `LLM_PROVIDER=openai`, `LLM_BASE_URL=http://localhost:11434/v1`, `LLM_MODEL=llama3.1` | локально, ключ не нужен |

Все инструкции — в `.env.example`. Для диалога подойдёт любая модель, умеющая
вызывать функции (function calling).

## Почему нет авто-рассылки

1. **Telegram.** Боты не могут писать первыми — только тем, кто сам нажал `/start`.
   Обойти это можно только через ваш личный аккаунт (юзербот). Telegram за такое
   блокирует аккаунт вместе с номером телефона: лимит для нового пользователя —
   порядка 20–30 сообщений незнакомцам в сутки, дальше бан. Жалобы «спам» ускоряют его.
2. **Закон.** Ст. 18 ФЗ «О рекламе»: реклама по каналам связи без предварительного
   согласия получателя запрещена. Штрафы выписывают и ИП, и компаниям.

Поэтому бот работает так: находит и готовит, а вы **отправляете сами** — вручную
через Telegram, звонком, WhatsApp или email. Согласие появляется с первым ответом.
В коде есть модуль полуручной отправки (`smm_bot/sender.py`), но он:
- берёт только лиды, которые вы одобрили руками;
- не больше 15 сообщений в сутки;
- пауза минимум 2 минуты между сообщениями;
- никогда не пишет тем, кто попросил не писать.

Даже с этими лимитами риск для личного аккаунта остаётся. Используйте на свой страх
и риск и только для людей, которых вы не спамите.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # и заполните TELEGRAM_BOT_TOKEN
```

Токен бота — у [@BotFather](https://t.me/BotFather). Свой user id для
`ALLOWED_USER_IDS` — у [@userinfobot](https://t.me/userinfobot), чтобы бот не отвечал
чужим.

## Запуск

Бот:

```bash
python -m smm_bot.bot
```

Команды в боте: `🔍 Найти клиентов`, `📋 Следующие лиды`, `📊 Статистика`,
`🗂 Категории`, `📤 Экспорт CSV`. В чате просто напишите город — бот найдёт лиды.

Без бота, из терминала:

```bash
python -m smm_bot.cli find "Тюмень" --categories cafe,banya,barber,beauty
python -m smm_bot.cli list --limit 10
python -m smm_bot.cli export --out data/leads.csv
python -m smm_bot.cli stats
```

Тесты:

```bash
python -m pytest tests/ -q          # 22 теста, сеть не нужна
python -m scripts.llm_smoke         # проверка LLM-клиентов
```

## Данные

Источник — OpenStreetMap через Overpass API. Это бесплатно, без API-ключей и
разрешено лицензией ODbL. Главный плюс: у объектов в OSM есть тег `website`,
поэтому «нет сайта» определяется достоверно, а не на глаз.

Учтите: в OSM у части заведений нет телефона. Такие лиды бот помечает
«контактов нет» — их можно добрать поиском вручную или через платные источники
(2ГИС, Яндекс.Карты — у них другая лицензия и условия использования).

  cli.py               работа из терминала

deploy/
  install.sh           установка на VPS одной командой

## Как повысить конверсию

- Пишите в рабочее время и о конкретной выгоде, а не «сделаю сайт».
- В первом сообщении не давайте ссылок — Telegram их не любит, а люди боятся.
- Начинайте с тех, у кого есть Telegram: там ответ приходит быстрее всего.
- Обрабатывайте ответы: «интересно» — предложите 15-минутный созвон;
  «нет» — фиксируйте «не писать» и больше не беспокойте.
